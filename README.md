# Recanto da Laranjeira — prévia comercial V2

Site institucional demonstrativo com identidade gráfica inspirada em laranjeiras: ilustração vetorial autoral no hero, cores botânicas e tipografia editorial. Publicação estática no GitHub Pages pela branch `main`, pasta `/ (root)`.

## Imagens e autenticação

As duas fotografias ilustrativas remotas vêm do Unsplash, com identificação explícita na interface; **não são fotografias do Recanto**. Substituir por imagens originais com autorização antes do lançamento definitivo. A ilustração de laranjeira é conceitual e não é logotipo oficial. Não foram extraídas fotografias do Google Maps para republicação.

## A confirmar

Fotografias e marca oficiais, capacidade e estrutura, condições de locação, categorias de eventos aceitas, horário para visitas/eventos, contato preferencial e autorização para publicação. O telefone/endereço são informações da ficha pública do Google.

## Publicação

GitHub → Settings → Pages → Deploy from a branch → main → / (root). O site não necessita Node em execução.

## Abertura cinematográfica

A primeira tela apresenta foto provisória de laranjeira (Unsplash), movimento parallax progressivo por scroll, folhas animadas em CSS e transição sticky para o conteúdo. Respeita preferências de movimento reduzido. A imagem é ilustrativa e **não retrata o Recanto**. A fotografia do hero vem da Unsplash, autor Philippe Gauthier, página: https://unsplash.com/photos/orange-fruits-under-blue-sky-during-daytime-eaOjEz8746k. Substituir por fotografia/vídeo oficial autorizado antes do uso definitivo.

## Abertura com queda da laranja (versão no GitHub Pages)

Na publicação atual, a laranja SVG com textura animada pelo scroll cai sobre uma foto de laranjeira. A sequência dos 4 quadros enviada pelo solicitante existe no ZIP V4 de demonstração, mas **não está incorporada à página online**. O efeito foi recriado em código para evitar dependência de imagens locais ausentes no repositório. A cena respeita `prefers-reduced-motion` e mantém o link para pular ao conteúdo.

Foto de laranjeira na abertura: Tim Mossholder — [Unsplash](https://unsplash.com/photos/a-tree-filled-with-lots-of-ripe-oranges-wtGWZbiDhGc), sob a licença Unsplash. A foto não retrata o estabelecimento. Recomendado obter autorização de uso comercial para qualquer imagem específica de terceiros incorporada na versão final.
